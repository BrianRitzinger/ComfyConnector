# ComfyConnector

A Blender addon that connects to ComfyUI, allowing you to generate AI images from within Blender and use Blender renders as inputs for ComfyUI workflows.

## Use Cases

- Send a Blender render to ComfyUI for img2img processing
- Pull AI-generated textures back into Blender
- Trigger ComfyUI workflows directly from Blender's UI

## Requirements

- Blender 4.x
- ComfyUI running locally (default: http://localhost:8188)
